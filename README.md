A structured SQL practice repository for HackerRank SQL challenges and SQL certification preparation.

This repository documents my SQL learning process through clean solution files, challenge tracking, concept notes, and review-ready progress logs. It is designed as a public portfolio artifact for SQL fundamentals, query readability, and interview preparation.

## Portfolio Focus

This repository supports preparation for data-related roles where SQL fluency is expected, including Data Analyst, Data Science, Product Analytics, and Applied ML/AI internships.

The work here focuses on:

- writing correct SQL queries from problem requirements;
- keeping each solution easy to review later;
- practicing SQL fundamentals before moving into harder query patterns;
- documenting progress without overstating certification status;
- keeping public learning artifacts clean, concise, and recruiter-readable.

## Solution Lifecycle

Accepted practice solutions are documented through this lifecycle:

1. Challenge completed on HackerRank.
2. Matching `.sql` template updated with the accepted query.
3. Short original task summary added.
4. Concise explanation added.
5. [CHALLENGES.md](CHALLENGES.md) and [notes/practice_log.md](notes/practice_log.md) updated.
6. Related accepted solutions grouped into a meaningful checkpoint.

Solution files use this structure:

```sql
-- Problem:
-- Track:
-- Difficulty:
-- Max score:
-- Concepts:
-- Status:
-- Source:
--
-- Task summary:
--
-- Query:
--
-- Explanation:
```

## Quality Standard

Accepted answers are the correctness baseline. Repository-ready solutions also include:

- accepted by HackerRank;
- written in a readable SQL style;
- limited to the requested output columns;
- documented with a short explanation;
- linked to the correct challenge template;
- reflected in the practice log.

The review standard is documented in [docs/sql_style_guide.md](docs/sql_style_guide.md) and [docs/review_workflow.md](docs/review_workflow.md).

## Practice Policy

HackerRank owns its platform content and challenge statements.

This repository stores:

- my own accepted practice queries after solving them;
- short task summaries written in my own words;
- concept notes and learning logs;
- public-safe certificate evidence after completion.

This repository does not store:

- live certification assessment questions;
- live certification assessment answers;
- private account screenshots;
- tokens, cookies, or credentials;
- copied long-form challenge statements.
