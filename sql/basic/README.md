# Basic SQL Practice

This folder contains 40 Basic-level HackerRank SQL practice templates.

## Focus Areas

- selecting all columns or specific columns;
- filtering rows with `WHERE`;
- using text and numeric conditions;
- removing duplicates;
- sorting output;
- basic aggregation;
- introductory joins;
- simple conditional logic.

## Completion Standard

Each completed file contains:

- `Status: Accepted`;
- the final accepted query;
- a short explanation;
- matching updates in `CHALLENGES.md` and `notes/practice_log.md`.
