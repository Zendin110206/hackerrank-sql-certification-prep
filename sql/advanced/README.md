# Advanced SQL Practice

This folder contains 4 Advanced-level HackerRank SQL practice files.

## Current Status

4 of 4 Advanced-level practice files are accepted on HackerRank and documented
in this repository.

## Focus Areas

- date-based streak logic;
- advanced grouping;
- recursive or generated output patterns;
- prime-number logic;
- query decomposition;
- explaining complex SQL clearly.

## Completion Standard

Advanced solutions include:

- an accepted query;
- a concise strategy explanation;
- notes on important edge cases;
- updated roadmap and practice log entries.

Live certification assessment content is outside the scope of this folder.
