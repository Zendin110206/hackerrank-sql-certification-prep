# SQL Practice Index

This directory stores SQL practice files organized by HackerRank SQL level.

## Levels

- `basic/` stores 40 Basic practice templates.
- `intermediate/` stores 13 Intermediate practice templates.
- `advanced/` stores 4 Advanced practice templates.

## File Convention

File names use lowercase snake_case with a numeric prefix:

```text
01_revising_the_select_query_i.sql
02_revising_the_select_query_ii.sql
```

The numeric prefix follows the practice order tracked in `CHALLENGES.md`.

## Solution File Standard

Each solution file follows this structure:

```sql
-- Problem:
-- Track:
-- Difficulty:
-- Max score:
-- Concepts:
-- Status:
-- Source:
--
-- Task summary:
--
-- Query:
--
-- Explanation:
```

Live certification assessment questions and copied long-form challenge statements are outside the scope of this repository.
