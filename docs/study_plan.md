# SQL Certification Study Plan

This study plan turns the challenge roadmap into practical milestones.

## Goal

The repository builds SQL fluency through accepted HackerRank practice, readable solution files, and documented review checkpoints before certification attempts.

## Phase 1: Basic SQL

Target: 40 Basic-level practice problems.

Core topics:

- `SELECT`
- `WHERE`
- comparison operators
- `DISTINCT`
- text filters
- sorting
- aggregation
- simple joins
- basic conditional logic

Completion criteria:

- all Basic templates contain accepted queries;
- every accepted query has a short explanation;
- `CHALLENGES.md` and `notes/practice_log.md` reflect the solved status;
- completed work is grouped into meaningful checkpoints.

## Phase 2: Intermediate SQL

Target: 13 Intermediate-level practice problems.

Core topics:

- multi-table joins;
- grouped aggregation;
- `HAVING`;
- subqueries;
- CTEs;
- self joins;
- anti-duplication logic;
- multi-step reasoning.

Completion criteria:

- all Intermediate templates contain accepted queries;
- each solution explains the query strategy;
- difficult problems include notes about false starts or edge cases;
- public documentation remains limited to original summaries and self-written solutions.

## Phase 3: Advanced SQL

Target: 4 Advanced-level practice problems.

Core topics:

- recursive or iterative output generation;
- prime-number logic;
- date-based streak logic;
- advanced grouping;
- query decomposition;
- readability under harder constraints.

Completion criteria:

- all Advanced templates contain accepted queries;
- explanations are strong enough for later review;
- certification attempts are tracked honestly in the README and practice log.

## Batch Review Cadence

A practical review batch is 3 to 6 accepted problems.

Each batch is tracked through:

1. updated solution files;
2. updated challenge roadmap;
3. updated practice log;
4. reviewed diff;
5. clear checkpoint message.

## Readiness Signal

The repository is ready to support a certification attempt when:

- recent practice is consistently accepted without copied answers;
- mistakes are understood and documented;
- query formatting is consistent;
- explanations are clear;
- each solved pattern can be explained without relying on an answer key.
