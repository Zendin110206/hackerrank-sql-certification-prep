# Assets

This directory is reserved for public-safe supporting assets.

## Folder Scope

- `certificates/` contains earned certificate images after completion.
- `screenshots/` contains optional public-safe visuals, such as anonymized progress evidence or repository previews.

Official credential links remain the primary verification source for certifications.

Private account data, session artifacts, credentials, and live assessment content are outside the scope of this directory.
