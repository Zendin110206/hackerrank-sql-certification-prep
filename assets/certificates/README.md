# Certificates

This directory is reserved for public-safe certificate images after the related credential has been earned.

## Naming Convention

```text
hackerrank-sql-basic-certificate-YYYY-MM-DD.png
hackerrank-sql-intermediate-certificate-YYYY-MM-DD.png
hackerrank-sql-advanced-certificate-YYYY-MM-DD.png
```

## Verification Policy

Certificate images are supporting evidence. Official credential verification links remain the primary source of truth and are listed in the root README after completion.

Images that expose private account information are not part of the public repository scope.
