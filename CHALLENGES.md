# Challenge Roadmap

This file tracks the full public practice roadmap for the HackerRank SQL path used in this repository.

Status values:

- `Not started` - template exists, query not written yet.
- `In progress` - query is being tested or revised.
- `Accepted` - query passed on HackerRank and the local file has an explanation.
- `Reviewed` - accepted query has been reviewed for style and documentation.
